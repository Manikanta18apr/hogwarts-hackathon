🌟 Features
1. AI Chatbot Local Guide

Ask natural questions such as:

“Where can I go for sunset today?”

“Best spicy street food near me?”

“Any cultural events tonight?”

The AI responds instantly with curated suggestions.

2. Personalized Recommendations

Tailored suggestions using user behavior + preferences + real-time context.

3. Hidden Gems Finder

Reveals lesser-known local spots that typical travel apps miss.

4. Event & Activity Discovery

Shows nearby:

Cultural activities

Workshops & meetups

Food events

Student-friendly gatherings

5. Smart Mini-Itinerary Generator

Creates optimized plans for:

1–3 hours

Half-day

Full-day
Based on distance, time, and user interests.

6. Community Reviews & Contributions

Locals and travelers can add new places, share experiences, and write reviews.

🛠️ Tech Stack

Frontend: React / Flutter
Backend: Node.js / Firebase
AI Models: OpenAI / Google Gemini APIs
Database: MongoDB / Firebase Firestore
Location Services: Google Maps API / Mapbox
